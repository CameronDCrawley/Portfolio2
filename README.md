## Cameron Crawley — Full-Stack Software Engineer Portfolio

Personal portfolio website for Cameron Crawley, a full-stack software engineer based in NYC specializing in modern websites for small businesses and technology solutions for public services and nonprofits.

## Live Site
https://camerondc.netlify.app/
## Overview

This portfolio highlights Cameron's background transitioning from NYC social services into software engineering, showcasing services offered, recent full-stack web applications, small business websites, and direct contact/booking options.

## Features

Accessible & Responsive Design: Built with semantic HTML5, ARIA labels, and Atkinson Hyperlegible + Bricolage Grotesque typography for maximum readability across desktop and mobile devices.

**SEO & Social Metadata:** Configured with Open Graph tags, Twitter Cards, and Schema.org JSON-LD structured data.

**Services Overview:** Outlines core offerings including small business web development, civic/public service tools, and beginner coding workshops.

**Project Showcase:** Direct links and previews for live full-stack applications and client websites.

**Integrated Contact & Booking:** Includes a Netlify-ready contact form alongside direct links to email, GitHub, LinkedIn, X, and Cal.com scheduling.

## Local Setup

`git clone https://github.com/CameronDCrawley/your-portfolio-repo.git
cd your-portfolio-repo`

`npx serve .`
