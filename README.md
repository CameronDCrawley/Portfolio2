**Cameron Crawley | Portfolio**

A personal portfolio website for Cameron Crawley, a full-stack software engineer in NYC who builds modern websites for small businesses and uses tech to connect people with public services.

**Features**
**About**: Introduces Cameron, his background in NYC social services, and his path into tech through 100Devs.
**Services Overview**: Highlights three focus areas: websites for small businesses, tech for public services, and beginner coding workshops.
**Project Showcase**: A grid of recent client and personal projects, each with a screenshot, tag, short description, and link to the live site.
**Contact Form**: A working contact form handled by Netlify Forms, plus email, social links, and a Cal.com booking link.
**SEO & Social Sharing**: Includes meta descriptions, Open Graph and Twitter card tags, and JSON-LD structured data so the site displays well in search results and when shared.
**Accessible Design**: Uses semantic HTML, ARIA labels, descriptive alt text, and the Atkinson Hyperlegible font for maximum readability.
Built With
- HTML
- CSS

**How It Works**
Visitors land on the hero section and can jump to About, Work, or Contact using the navigation bar.
The Work section displays project cards that open each live site in a new tab.
When a visitor submits the contact form, Netlify detects the data-netlify="true" attribute and captures the submission, which is then sent to Cameron's inbox.
Visitors who prefer to schedule a call can use the Book Me link to pick a time through Cal.com.
